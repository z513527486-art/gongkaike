# 公开课互动课件 Skill 包

这是为中国中小学语文公开课设计的互动课件技能目录。

目录结构：
- SKILL.md：技能说明书，定义生成规则与公开课式结构
- assets/：素材、样式和图片资源目录
- scripts/：构建与校验脚本
- references/：设计、实现和验收说明
- examples/：示例课例数据

使用方式：
1. 把整个目录打包后导入豆包或其他支持本地技能导入的客户端。
2. 直接运行脚本生成单文件 HTML。
3. 在浏览器中使用 `file://` 方式验收。

核心目标：
- 以文本为主导
- 以公开课结构为主线
- 以 VR 全景 + 平面交互 + 课题训练为拓展方式
- 最终交付单文件 HTML
