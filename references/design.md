# 设计原则：公开课式视觉与教学叙事

公开课型课件不是单纯展示素材，而是以“课堂推进”为核心。所有设计要围绕文本阅读、景物观察、问题探究和练习提升展开。

## 1. 视觉层次

- 先建立主视觉：封面、标题、课程提示、主题意象
- 再建立支持层：导图、时间线、章节结构、文本框
- 最后做辅助层：页脚提示、按钮、标签和状态反馈

## 2. 空间组织

- 全景页面负责“进入情境”，强调整体空间和环境感
- 热点页面负责“发现细节”，对文本中的关键意象进行局部展示
- 平面交互页面负责“理解与训练”，承接观察、讨论和课题任务

## 3. 公开课审美

- 页面留白必须适中，不能塞满信息
- 标题和模块名称应明确表达教学阶段
- 图与文的关系要明确：图是证据，文是解释，问题是引导

## 4. 质量门禁

- 图像要和文本真实对应，不可纯装饰
- 交互不宜复杂到失去教学目的
- 每一页都要有一个明确的课堂任务
