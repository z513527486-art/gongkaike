# 全景设计：从“情境进入”到“细节发现”

## 1. 全景不是展示墙，而是带学生进入场景

全景页面的关键任务：让学生从整体环境中感知文本情境，知道“这篇文章发生在哪里”“这里有些什么”“我应该看什么”。

建议使用固定镜头、可拖动和可切换视角的方式，使学生获得沉浸感，但不应出现失控的自由漫游。

## 2. 热点设计

每个热点都应该对应真实、可观察、可描述的对象。热点不只是“点一下显示说明”，而是：

- 提供一个观察视角
- 连接一处文本证据
- 引发一层思考

## 3. 视角设计

优先安排三种镜头：
- 总体全景：让学生看到环境与空间关系
- 中景定位：让学生看到人物或场景核心
- 局部特写：让学生看到细节、动作、意象、情绪

## 4. 公开课中的全景

在公开课展示中，全景的效果不应只是“好看”，而要更具“讲课价值”：
- 让教师能讲清 scene/space/transition
- 让学生能观察并找证据
- 让任务明确并可被讨论
